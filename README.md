📖 About

School Rush is a game where you are racing against the clock to get to your class. You also have side quests with bonus apples that can be collected. Apples can be used in the store to buy bonus items. Can you get to your class in time, or will you fail?

✨ Features:

-In-Game store where the player can purchase power-ups and accessories

-Side quests the player can complete for bonus apples to use in the store

-Mini-map which shows the player where each of the classes are 

🛠️ Technologies:

Game engine: Unity

Language: C#
